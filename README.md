# Fried-YouTube-Downloader
My first ever piece of utility I made :)

It's like those youtube to mp4 stuff on the web except free from ads and much quicker than them<br>
Enjoy if you use!<br>
<br>
(This for now by default saves to your downloads folder by the way, works for any OS as long as you have a downloads folder!)<br>

## Dependencies you need to install
- python 3
- pytubefix

- pyinstaller (optional)

## Install instructions
1. Make sure you install the dependencies listed above.
2. Using `git` via CLI, run `git clone https://github.com/zelafrites/Fried-YouTube-Downloader.git`, or download this repo manually
3. Via CLI, `cd` into the working directory of the copied project, and run `pyinstaller --onefile main.py`
4. Once pyinstaller compiles the program for you, you can run the file created

Alternatively, you can simply just run main.py with python.
